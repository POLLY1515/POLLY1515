# Projeto em destaque 🚀


## Sistema de Vendas - API REST Backend

🔗 https://github.com/POLLY1515/Sistema-de-vendas


API REST backend desenvolvida em Java 21 e Spring Boot para gerenciamento de operações comerciais, aplicando conceitos utilizados em aplicações profissionais como autenticação, segurança, persistência de dados e arquitetura em camadas.

A aplicação foi construída utilizando:

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- PostgreSQL
- Maven
- Docker
- Swagger/OpenAPI


## Funcionalidades desenvolvidas

✔ Desenvolvimento de API REST

✔ Gerenciamento de clientes

✔ Gerenciamento de produtos

✔ Operações relacionadas a vendas

✔ Persistência utilizando Spring Data JPA

✔ Modelagem de entidades

✔ Validação de dados

✔ Implementação de regras de negócio

✔ Controle de acesso utilizando autenticação

✔ Tratamento de erros
