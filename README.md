## Projeto em destaque

### [Sistema de Vendas](https://github.com/POLLY1515/Sistema-de-vendas)

API REST desenvolvida com **Java 21, Spring Boot e PostgreSQL** para gerenciamento de produtos, clientes e operações de vendas.

O projeto está sendo utilizado para aprofundar conhecimentos em desenvolvimento backend, regras de negócio, persistência de dados e organização em camadas.

**Principais pontos trabalhados:**

- arquitetura em camadas;
- endpoints REST;
- persistência com Spring Data JPA;
- validação de dados;
- PostgreSQL;
- tratamento de regras de negócio;
- organização de entidades, services, repositories e controllers.

**Melhorias em andamento:**

- separação entre DTOs e entidades;
- tratamento centralizado de exceções;
- testes unitários e de integração;
- migrations com Flyway;
- Dockerfile e Docker Compose;
- pipeline com GitHub Actions;
- documentação da API.
